### ⚡ What I Do

- 🛒 **E-Commerce Automation:** Custom WooCommerce plugin engineering, external REST API integrations (e.g., G4A4 API), and automated digital product fulfillment.
- 🤖 **Bot Architecture:** Automated multi-platform bots across **Discord**, **Telegram**, **Bale**, and **Rubika** (ticketing, store notifications, live inquiry panels).
- 💻 **Backend & Web:** Practical, product-focused engineering using **Python**, **PHP**, and **TypeScript** (WordPress, Next.js, Flask, SQLite/PostgreSQL).
- ⚙️ **Performance Philosophy:** Building low-memory, lightweight solutions optimized for resource efficiency.
